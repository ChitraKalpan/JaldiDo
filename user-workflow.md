# JaldiDo User Workflow

## Create a share session

1. Open JaldiDo on the device that has the content to share.
2. Choose **Create Share** to start a temporary session.
3. Share the displayed six-character access code, or let the other device scan the QR code.

## Join from another device

1. Open JaldiDo on the receiving device.
2. Enter the access code, or open the join link from the QR code.
3. Join the active session to see its shared content.

## Share content

- Upload files from either connected device; the other device can download them.
- Send text or links in the session.
- Remove shared files when they are no longer needed.

## Start another session

A device can create or join sessions again. Use **Create New Session** to start a fresh share after completing or leaving the current one. Sessions are temporary and expire according to the configured session lifetime.

## Backend behavior

JaldiDo uses ordinary application logic for session creation, access-code validation, joining, file and text sharing, and expiry. The backend does not use AI models or AI APIs.
